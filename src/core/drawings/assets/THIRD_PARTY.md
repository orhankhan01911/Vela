# Third-party art in this folder

- `twemojiSprite.ts`: Twemoji 15 graphics, Copyright 2019 Twitter, Inc. and other contributors
  (https://github.com/jdecked/twemoji). Licensed under CC-BY 4.0 (https://creativecommons.org/licenses/by/4.0/).
  The art is used unchanged except for number rounding (two decimals) and the shared `<svg>` wrapper being removed.
  The Icons panel credits it ("Emoji art: Twemoji (CC-BY 4.0)").
- `faIcons.ts`: glyph outlines from Font Awesome 4.7 by Dave Gandy (https://fontawesome.com/v4), font licensed under
  the SIL Open Font License 1.1 (https://scripts.sil.org/OFL). Only the 136 glyphs TradingView's icon tool offers.
- `emojiGroups.ts` and the icon group lists: which Unicode emoji / Font Awesome code points TradingView's picker offers,
  and in what order (plain data, read from TradingView's code on 2026-10-30).
